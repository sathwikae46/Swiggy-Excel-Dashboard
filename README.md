# 📊 Swiggy Sales Dashboard

An interactive Swiggy Sales Dashboard built using **Microsoft Excel** to analyze sales data and generate business insights.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
